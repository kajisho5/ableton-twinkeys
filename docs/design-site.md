# 紹介サイト（GitHub Pages）— 設計書

- 状態：**確認待ち**（この設計書と `docs/design/site-*.svg` を承認いただいてから作成）
- 作成日：2026-11-09
- 公開先：`https://kajisho5.github.io/ableton-twinkeys/`（リポジトリ名を `twinkeys` に変えた場合は `…/twinkeys/`）

## 1. 目的

TwinKeys を知らない人が、次の3つを1ページで分かるようにする。
- 何をするアプリか
- 安全に使えるか（公証済み、合言葉による暗号化、非公式ツールであること）
- どこからダウンロードし、どう始めるか

あわせて、使い方（docs/help）を Web でも読めるようにする。

## 2. 技術の選び方

| 観点 | A. Astro（おすすめ） | B. 手書きの HTML 1枚 | C. Jekyll（GitHub Pages 標準） |
|---|---|---|---|
| 動作の軽さ | とても良い（できあがりは HTML だけ） | とても良い | 良い |
| 配布サイズ | 小さい | 最小 | 小さい |
| 作りやすさ | 使い方の Markdown（docs/help）をそのまま取り込める。英語・日本語の2ページも部品を共有できる | 2言語と使い方ページを手で二重に管理することになる | Ruby の環境が必要。テーマの自由度が低い |
| 将来性 | 活発（7.4.7、2026-11-05） | — | 更新はゆっくり |
| AI での書きやすさ | 良い | 良い | 普通 |

**おすすめは A. Astro です。** あなたの決まり（表示中心のサイトは Astro）とも合っています。使い方の文章はアプリと同じファイルから作るので、二重に管理しなくて済みます。
- Astro 7.4.7 **[事実]** https://www.npmjs.com/package/astro （必要な Node は 22.23.4 以上）
- 公開は GitHub の公式部品 configure-pages v6.0.0、upload-pages-artifact v5.0.0、deploy-pages v5.0.1 **[事実]** https://github.com/actions/deploy-pages

## 3. ページ構成

| ページ | 内容 |
|---|---|
| `/`（英語）と `/ja/`（日本語） | 上部の帯（見出し、説明、ダウンロード、使い方へのボタン、動作環境、公証済み・非公式の一文、アプリの画面）、しくみ（3つの箱と矢印）、できること（6つ）、はじめかた（4手順）、フッター（制作者、MIT、商標の注記、GitHub） |
| `/guide/` と `/ja/guide/` | 使い方。`docs/help/en.md` と `ja.md` をそのまま表示する |

- **ダウンロードのボタン：** GitHub の最新リリースのページ（`/releases/latest`）へのリンク。1.0.0 からは正式版なので、このリンクで最新版が開く。
- **言語：** 右上のリンクで英語と日本語を切り替える。
- **外観：** ライト／ダークは、端末の設定に自動で合わせる。
- **画面写真：** `deliverables/screenshots` の写真を使う（アプリの見た目と同じもの）。

## 4. デザイン（`docs/design/site-*.svg`）

| ファイル | 内容 |
|---|---|
| `site-desktop-light-ja` | パソコン・ライト・日本語（ページ全体） |
| `site-desktop-dark-en` | パソコン・ダーク・英語（ページ全体） |
| `site-mobile-light-ja` / `site-mobile-dark-en` | iPhone（幅 390）での上部 |

- **色：** アプリのアイコンと同じ紺のグラデーションを上部の帯に使う。強調色はアプリと同じ青（ライト #0060C7、ダーク #5AA9FF）。
- **文字：** システムの文字（日本語はヒラギノ、Noto Sans JP）。自作ツールのサイトなので、SEVENTHWELL のブランド用フォントは使わない。
- **読みやすさ：** 文字と背景の見分けやすさ（コントラスト）は、本文で 4.5:1 以上。
- **スマートフォン：** 左右の余白は 16px。横にはみ出してスクロールしない。

## 5. 作るもの

- `site/`：Astro のプロジェクト（ページ、部品、CSS）
- `.github/workflows/pages.yml`：`main` の `site/` と `docs/help/` が変わったら自動で組み立てて公開する
- **最初に一度だけ、あなたの操作が必要：** リポジトリの設定で Pages の公開元を「GitHub Actions」にする（手順は公開時にお伝えします）
