## 1. 背景

使い方：音響のキュー出し。矢印キーでシーンを選び、スペースなどで再生する。Live 側で、キーごとに次のような割り当てをする。
- シーンの上下移動
- 選んだシーンの再生
- 再生／停止

Live では、これらを MIDI で割り当てられる。
- 再生・停止などの操作ボタン（Control Bar の transport）
- シーンの上下移動と「選んだシーンの再生」（Relative Session Mapping Strip）
- 個別のクリップやシーン

**[事実]** https://www.ableton.com/en/manual/midi-and-key-remote-control/

**今の TwinKeys で足りないこと**

1. **送れるキーが足りない。** 送れるのはピアノ配列の17個（A〜;、W〜P）だけで、矢印キー・スペース・リターンは送れない。
2. **オクターブが変わる。** Z / X を押し間違えると、同じキーでも別のノートになり、Live の割り当てから外れる。
3. **メインで2回動く。** 今の TwinKeys はキーを見ているだけで、キーはそのまま Live にも届く。
   - Live が前面にあると、メインの Live は矢印キーやスペースそのものにも反応する。
   - さらに TwinKeys からの MIDI にも反応するので、たとえば「次のシーン」が2つ進む。
   - バックアップは MIDI だけなので1つしか進まず、2台がずれる。**[推測：Live の矢印キー・スペースの標準の動きとの重なり。実機で確認]**

## 2. 決めたいこと（案）

### 2.1 キューのキー

- 好きなキーを登録できるようにする：矢印、スペース、リターン、Esc、数字、F1〜F12 など。修飾キー付き（⌘ など）は今までどおり送らない。
- 登録したキーには、決まった MIDI ノートを割り当てる。
  - チャンネル 2。番号は登録した順に C1 から。
  - オクターブやベロシティの切り替えに影響されない。ベロシティは 127 で固定。
- キーにはメモ（自分用の名前。例「次のシーン」）を付けられる。
- キーを押しっぱなしにしたときの連打（キーリピート）は送らない。1回押せば1回だけ。
- 最初から入れておく例：↑ ↓ Space Return Esc（あとで消せる）。

### 2.2 キーをほかのアプリに渡さない（おすすめ・最初はオン）

- 登録したキューのキーは、TwinKeys が受け取り、Live を含むほかのアプリには渡さない。
- メインの Live も、TwinKeys の MIDI だけで動く。2台が同じ動きになり、Live が前面にあるかどうかにも左右されない。
- 渡さないのはキー入力がオンのときだけ。⌃⌘K でキー入力をオフにすると、矢印キーなどがふだんどおり使える。
- **macOS の許可について**
  - キーを横取りするには「アクセシビリティ」の許可が要る **[推測：Apple 公式の資料では未確認。開発者フォーラムの情報。実装時に CI と実機で確認]**
  - 見るだけなら、今の「入力監視」の許可で足りる。
  - 許可が無いときは見るだけで動き、画面の下に「キーをほかのアプリに渡しています（2回動くおそれ）」と出す。
- 参考（いずれも Apple の開発者フォーラム。公式の資料ではない）：
  - https://developer.apple.com/forums/thread/735204
  - https://developer.apple.com/forums/thread/758554

### 2.3 ピアノ配列のキー

- 設定に「ピアノ配列のキーも使う」を置く。
- キュー出しでは押し間違いを防ぐため、**新しく入れたときはオフ**にする。0.5.0 から更新した人は今までどおりオン。

### 2.4 直前のキューの表示（`design-update.md` の7章を変更）

- ノート名（C3）ではなく、押したキー（↓）とメモ（次のシーン）を大きく出す（`cuekeys-panel-*`）。
- バックアップにも同じ表示を出すため、接続したときに、メインが「キーとメモの一覧」をバックアップへ送る（暗号化は今と同じ）。

## 3. 画面（`docs/design/cuekeys-*`、ライト／ダーク）

| ファイル | 内容 |
|---|---|
| `cuekeys-settings-*` | 設定の「キューのキー」：一覧（キー、メモ、MIDI）、「キーを追加…」、ほかのアプリに渡さない、ピアノ配列 |
| `cuekeys-add-*` | キーを追加するときのシート：「登録したいキーを押してください」 |
| `cuekeys-panel-*` | メインとバックアップの「直前のキュー」 |

## 4. 使い方（ヘルプに書く手順）

1. TwinKeys の設定で、使うキーを登録する。
2. 2台の Live で、MIDI 割り当てモード（⌘M）に入る。割り当てたいもの（シーンの上下、再生など）をクリックし、メインの Mac でそのキーを押す。
3. 割り当ては2台で同じにする（同じセットのファイルを使うのが確実）。
4. Live の「キーの割り当て」（⌘K）で同じキーを割り当てていたら、消す。残すとメインで2回動く。

## 5. テスト

- 単体テスト
  - 登録したキーが決まったノートになる（オクターブを変えても同じ）
  - キーリピートを送らない
  - 修飾キー付きは送らない
  - ピアノ配列オフでは A などが送られない
  - 設定の保存と読み込み（0.5.0 の設定からの引き継ぎ）
- CI：キーとメモの一覧がバックアップに届く（e2e）
- 実機の手順書
  - キーを渡さない設定で、Live の矢印キー・スペースが2回動かない
  - キー入力をオフにすると、ふだんどおり使える
