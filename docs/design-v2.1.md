## 1. GO 画面（台本モード）

キュー出しを「次のシーンを1つずつ進める」形で行うための画面。演劇やライブで、決まった順番どおりにきっかけを出すときに使う。

- 台本は Live のシーンの並びそのもの（別にリストを作らない。2台で同じセットなら同じ台本になる）。
- 左上「いま再生中」：再生中のシーンの番号・名前・残り時間（クリップの長さから計算、2.0 と同じ）。
- 左中「次」：Live で選んでいるシーン（「Live の選択に追従」と同じ）。
- 右の大きな「GO」：次のシーンを再生し、選択を1つ下に進める（`fireScene(next)` と `selectScene(next+1)`）。2台の Live に同時に届く。
- 「◀ 前へ」「次へ ▶」：次に鳴らすシーンを選び直すだけ（鳴らさない）。
- 本番ロック中も GO・前へ・次へは使える（ロックが止めるのはテンポとミキサーだけ）。
- 二度押し対策：GO を押してから 0.5 秒は次の GO を受け付けない。
- 右端の切り替えの帯に「GO」を足す（セッション・ミキサー・キュー・GO・設定）。

## 2. バックアップの Live の状態（iPhone の上の帯）

2.0.1 で、バックアップの Mac が「自分の Live が応答しているか」をメインに伝えるようになった（画面には未表示）。

- ふだん：`Main ✓ Backup ✓ Live ✓` と遅延（緑の点）。
- バックアップの Live が応答しない：`Live ✗` と「Live 応答なし」を黄色で出す（点も黄色）。
- キュー画面の「バックアップの Mac」の行にも同じ状態を出す。
- Mac の画面でも、接続済みの行に「バックアップの Live ✓／✗」を足す。

## 3. 2台のセットの見比べ

2台で違うセット（曲順や版が違う）を開いていると、同じキュー・同じクリップ番号で違う音が鳴る。本番前に気づけるようにする。

- バックアップの Mac は、自分の Live のトラックとシーンの「数と名前の要約」（ハッシュ）をメインに送る（つながったとき・セットが変わったとき）。
- メインは自分のセットと比べ、違えば警告を出す。
  - Mac：画面の上に黄色の帯「バックアップの Live のセットが違います」と、違いの数。「詳しく…」で違う行の一覧。
  - iPhone：上の帯の下に黄色の帯。押すと違いの一覧（図の D）。
- 比べるのはトラック・シーンの数と名前だけ。クリップの中身やミキサーの値は比べない。
- 自動で直すことはしない（本番中にセットを書き換えるのは危ないため）。
