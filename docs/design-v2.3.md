# TwinKeys 2.3 の設計案（承認待ち）

画面の図は `docs/design/` にあります（中身は架空のサンプル）。

| 図 | 内容 |
|---|---|
| `remote-switch-dark` | iPhone：メインの Mac が止まったときに、バックアップへ切り替える |
| `mac-switch-dark` | バックアップの Mac：「この Mac をメインにする」 |
| `watch-dark` | Apple Watch：GO と全ノートオフ |
| `remote-lock-options-dark` | iPhone の設定：本番ロックで止めるものを選ぶ |

## 1. バックアップへの切り替え

メインの Mac が止まった（フリーズ・電源断）ときに、すぐバックアップでキュー出しを続けるための機能。音の出口（ミキサー卓の入力）の切り替えは今までどおり人が行う。TwinKeys がするのは「キューを出す側」の入れ替え。

- iPhone：メインの Mac から 3 秒応答がないと、上の帯の下に赤い帯「メインの Mac が応答しません」と「バックアップに切り替える」ボタンを出す（図 A）。
- 押すと確認を出す。決定は 1 秒の長押し（図 B）。決めると iPhone はバックアップの Mac につなぎ直し、バックアップの Mac に「メインになって」と伝える。
- バックアップの Mac は、メインになると自分のキーボードのキューをオンにする（「キーを送信」をオン）。画面に「この Mac がメイン」と出す（図 `mac-switch`）。キーボードの前にいる人も、同じ画面の「この Mac をメインにする」で切り替えられる（確認つき）。
- 元のメインが戻ってきたら、そちらは自動で「受信だけ」にする（2台が両方キューを送って音が2回鳴るのを防ぐ）。「メインに戻す」で元に戻す。
- 条件：バックアップの Mac でも iPhone の接続を受け付けていて、この iPhone を許可済みであること（2.0 からある設定）。条件を満たさないときはボタンを出さず、「バックアップの Mac で TwinKeys Remote を許可してください」と出す。

## 2. Apple Watch

- iPhone の TwinKeys Remote を経由して動く（Watch から Mac には直接つながない。暗号の鍵を Watch に置かないため）。
- 画面は2枚だけ：GO（台本）と全ノートオフ。左右のスワイプで切り替え、デジタルクラウンで次に鳴らすシーンを選ぶ。
- 押すと手首が振動して確かめられる。本番ロックは iPhone と同じ。

## 3. 本番ロックの細かい設定

- iPhone の設定に「本番ロックで止めるもの」を足す：テンポ／ミキサー／クリップ・シーンの再生／停止・全クリップ停止／キューのボタン。
- 初期値は今と同じ（テンポとミキサーだけ止める）。
- 全ノートオフとロックの解除（1 秒長押し）は、どの設定でも止めない。
- Mac 側も同じ設定で断る（iPhone からロックの中身も送る）。

## 4. 公式サイト

- トップページに「TwinKeys Remote」の段を足す。iPhone の画面の画像（CI で撮った架空のサンプル）、できることの3行、TestFlight／App Store への案内。今のサイトの見た目（色・文字・余白）に合わせ、新しいデザインは作らない。
