# プライバシーポリシー

最終更新日：2026年11月12日

このポリシーは、Shogo Kajiyama / SEVENTHWELL が作っている **TwinKeys Remote**（iPhone・iPad アプリ）と **TwinKeys**（Mac アプリ）についてのものです。

## まとめ

- TwinKeys Remote は、**データを一切集めません**。制作者にも、ほかの誰にも送りません。
- アカウント、利用状況の分析、広告、トラッキング（ほかのアプリやサイトをまたいだ追跡）、アプリ内課金はありません。
- 通信の相手は、**あなた自身の Mac** の TwinKeys だけです。手元のネットワーク（ローカルネットワーク）の中だけで通信し、インターネットにはつなぎません。

## iPhone・iPad の中に保存するもの

- **合言葉** …… Mac と同じ合言葉を知っていることを示すために使います。iOS のキーチェーン（パスワードなどを守って保存する場所）に、この端末の中だけに保存します。
- **端末の鍵**（端末の中で作る秘密の鍵）…… 一度許可した iPhone を、Mac が次から見分けるために使います。iOS のキーチェーンに保存し、この端末の外には出しません。
- **ランダムな端末 ID、前回つないだ Mac の名前、設定**（「フェーダーの上限を 0dB にする」など）…… つなぎ直しと、設定を覚えておくために使います。アプリの保存場所（この端末の中）に保存します。

## 何を、どこへ送るか

- 送り先は、**同じネットワークにあるあなたの Mac の TwinKeys だけ**です。Bonjour（同じネットワークの機器を自動で見つける仕組み）で探し、TCP でつなぎます。
- つなぐときに、ランダムな端末 ID、iOS が示す端末の名前（ふつうは「iPhone」「iPad」だけ）、端末の鍵の公開用の半分を送ります。そのあとは、あなたの操作（再生、停止、クリップ、フェーダー、キューなど）を送り、Live の状態（トラック、シーン、クリップの名前、テンポなど）を受け取ります。
- 通信は Apple の CryptoKit で暗号化します（X25519 による鍵の交換、HKDF、ChaCha20-Poly1305）。合言葉が同じで、しかも Mac で許可した端末だけがつながります。
- メインの Mac は、つなぎ直せるように、許可した端末の一覧（ID、名前、公開用の鍵、日付）を保存します。いつでも Mac から消せます。

**ローカルネットワークの許可について：** iOS が「ローカルネットワーク上のデバイスの検索」の許可を求めます。あなたの Mac の TwinKeys を見つけてつなぐためだけに使います。

## 制作者に見えるもの

何も見えません。このアプリのためのサーバーは持っておらず、アプリからデータを受け取ることもありません。iOS の設定で「App デベロッパと共有」をオンにしている場合だけ、Apple から個人が分からない形のクラッシュ情報や利用数が届くことがあります。「設定」>「プライバシーとセキュリティ」>「解析および改善」でオフにできます。

## 保存の期間と消し方

- データは、あなたが消すまで、あなたの端末の中にだけあります。制作者は何も受け取っていないので、制作者の側で消すものはありません。
- Mac から iPhone の許可を取り消すには：メインの Mac の TwinKeys の「設定」>「許可した端末」で「取り消す」を押します。
- iPhone の中のデータを消すには：アプリを削除します。iOS の仕組みで、アプリを削除してもキーチェーンの中身（合言葉と端末の鍵）がその端末に残ることがあります。残ったものはその端末の中だけにあり、アプリを入れ直したときにだけ使われます。

## Mac 版の TwinKeys について

- TwinKeys は、キューとノートを、同じネットワークのもう1台の Mac と TwinKeys Remote にだけ送ります。
- 新しいバージョンを確かめるために、GitHub（api.github.com）にリリースの一覧を問い合わせ、新しいバージョンを GitHub からダウンロードします。ふつうのウェブの通信と同じく、GitHub には IP アドレスが届きます。くわしくは [GitHub のプライバシーに関する声明](https://docs.github.com/ja/site-policy/privacy-policies/github-general-privacy-statement)を見てください。自動の確認は、TwinKeys の「設定」の「アップデート」でオフにできます。
- 設定とログは Mac の中にだけ保存します（`~/Library/Application Support/TwinKeys/` と `~/Library/Logs/TwinKeys/`）。
