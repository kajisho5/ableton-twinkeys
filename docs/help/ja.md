# TwinKeys の使い方

TwinKeys は、音響のきっかけ（キュー）出しを2台の Mac で同時に行うためのアプリです。2台で同じ Live セットを開き、キーにクリップの再生を割り当てておけば、メインの Mac でキーを叩くだけで、バックアップの Mac でも同じクリップが同時に再生されます。メインの Mac が止まっても、バックアップにすぐ切り替えられます。

※ 非公式のサードパーティ製ツールです。Ableton 社とは関係ありません。

## 用意するもの

- macOS 13 以降の Mac を2台（メインとバックアップ）
- 2台が同じネットワークにつながっていること（有線 LAN、自分で用意したルーター、または2台を直接つなぐ LAN ケーブル1本）
- 両方の Mac に同じ Live セット

## はじめて使うとき

1. 両方の Mac で TwinKeys の .dmg を開き、TwinKeys を「アプリケーション」にドラッグしてから開きます。
2. ローカルネットワークの利用を確認されたら「許可」をクリックします。
3. メインの Mac では、ウインドウ上部の案内にある「システム設定を開く…」をクリックし、「入力監視」で TwinKeys をオンにします。戻ったら「もう一度確認」をクリックします。
4. メインの Mac では、「アクセシビリティ」でも TwinKeys をオンにします（「システム設定」>「プライバシーとセキュリティ」>「アクセシビリティ」）。キューのキーをほかのアプリに渡さないために使います。許可がないと、ウインドウに案内が出ます。

## 合言葉（最初に一度だけ）

2台で同じ合言葉を使います。合言葉が同じ Mac どうしだけがつながり、通信の中身も暗号化されます。

1. 片方の Mac で「合言葉を設定…」をクリックし、「新しく作る」をクリックします。K7MQ2-WX9TP のような10文字が出ます。
2. もう片方の Mac で「合言葉を設定…」>「合言葉を入力…」をクリックし、同じ10文字を入れます。大文字・小文字やハイフンの有無は区別しません。
3. 合言葉はキーチェーンに保存されるので、次からは入力する必要はありません。

## Live の設定（両方の Mac）

1. Live の「環境設定」（⌘,）を開き、「Link, Tempo & MIDI」タブを選びます（Live 11 では「Link/Tempo/MIDI」）。
2. テンポや小節に合わせて再生するセットでは、「Link」をオンにします（テンポと小節の位置は Link が合わせます）。
3. MIDI ポートの一覧で、入力「TwinKeys」の「リモート」をオンにします。「トラック」は不要です（オンにすると、割り当てていないキーの音がアームした MIDI トラックで鳴ることがあります）。
4. キューを割り当てます。Live の右上の「MIDI」ボタン（⌘M）を押して MIDIマップモードにします。割り当てたいもの（クリップのスロット、シーンの上下移動、選んだシーンの再生、再生・停止のボタンなど）をクリックしてから、メインの Mac で TwinKeys のキューのキー（↓ など）を押します。もう一度「MIDI」を押して終わります。
5. 割り当ては2台で同じにしてください（同じセットのファイルを使うのが確実です）。
6. Live の「キーマップモード」（⌘K）で同じキーを割り当てていたら、消してください。残すとメインの Mac で2回動きます。
7. クリップのローンチモードは「Trigger」のままにしてください。「Gate」や「Repeat」にすると、キューのキーを離したとたんにクリップが止まります（回線が切れて TwinKeys がノートオフを送ったときも止まります）。
8. メインの Mac では、Live の「コンピューターMIDIキーボード」をオフにします（ショートカットは M）。オンのままだと、英字のキーでも Live が音を出します。

## つなぐ

1. 両方の Mac で TwinKeys を開きます。
2. メインの Mac で「キーを送信」、バックアップの Mac で「ノートを受信」にチェックを入れます。
3. メインの Mac の「近くの TwinKeys」に相手の Mac が出たら、「接続」をクリックします。
4. 上の欄が「（相手の名前）に接続済み」になり、遅延が表示されればつながっています。

相手が一覧に出ないときは、「IPアドレスで接続…」（⇧⌘K）から相手の IP アドレスを入れます。相手の IP アドレスは、相手の Mac の「設定」>「合言葉」に出ています。

回線が途切れても、TwinKeys が自動でつなぎ直します（はじめは1秒ごと、だんだん間隔をあけて最大5秒ごと）。

## キューのキー

キューを出すキーは、「設定」（⌘,）の「キューのキー」で決めます。最初は ↑ ↓ ← → Space Return Esc が入っています。Mac のどのキーでも登録できます。

- 「キーを追加…」をクリックして、使いたいキーを続けて押すと、まとめて登録されます。英字・数字・矢印・スペース・F1〜F12 など、どのキーでも使えます。
- 「英字と数字をまとめて追加」で、A〜Z と 0〜9 を一度に登録できます。
- いらないキーは、一覧の右の「−」で消せます。
- キーごとに「メモ」（例：次のシーン）を付けられます。画面の「直前のキュー」に出ます。
- キューのキーは、それぞれ決まったノート（MIDI チャンネル 1、C1 から順、ベロシティ 127）を送ります。ほかのキーを消しても、残ったキーのノートは変わらないので、Live の割り当てはそのまま使えます。
- キーは文字ではなく位置で判定しています。JIS 配列でも US 配列でも、同じ場所のキーは同じキューになります。
- 押しっぱなしにしても、1回しか送りません。⌘・⌃・⌥・Shift と一緒に押したときは送りません。
- 「キューのキーを、ほかのアプリに渡さない（おすすめ）」がオンのとき、キューのキーは Live を含むほかのアプリには届きません。メインの Live も TwinKeys の MIDI だけで動くので、2台が同じ動きになります。「キー入力」をオフ（⌃⌘K）にすると、矢印キーなどはふだんどおり使えます。

## 直前のキューと、届いたかの確認

画面の上の方に「直前のキュー」が出ます。

- 押したキー、メモ、「接続してから○回目」が出ます。バックアップの画面にも同じものが出るので、2台の回数を見比べれば、同じキューにいるか分かります。つなぎ直すと 1 から数え直します。
- **バックアップに届きました**（緑の ✓）…… バックアップがキューを受け取りました。
- **届いた確認がありません**（赤）…… 約 0.3 秒のあいだ、0.1 秒ごとに送り直しても返事がありませんでした。バックアップでそのキューが出ているか確かめてください。それより遅れてキューが出るとかえって危ないため、送り直しはそこでやめます。
- **届いたかは確認できません** …… 相手の TwinKeys が 1.0.0 より前です。両方を 1.0.0 以降にしてください。

ほかのアプリで文字を打つときは、「キー入力」をオフにしてください（⌃⌘K）。

## ショートカット

- 接続／接続解除 …… ⌘K（相手が1台だけのとき。複数あるときは一覧の「接続」をクリック）
- キー入力のオン／オフ …… ⌃⌘K
- オールノートオフ …… ⌃⌘P
- IPアドレスで接続 …… ⇧⌘K
- 設定 …… ⌘,
- この使い方 …… ⌘?

## アップデート

- 新しいバージョンが出ると、自動でダウンロードしておきます（起動の1分後と6時間ごとに確認）。
- 準備ができると画面の上に知らせが出ます。入れ替えは **TwinKeys を終了したときだけ** です。本番中に勝手に入れ替えたり、再起動したりはしません。
- 接続していないときだけ「いま再起動」ボタンが出ます。
- ダウンロードしたアプリは、今のアプリと同じ開発者の署名があるか確かめてから使います。
- 自動で確認したくないときは、「設定」の「アップデート」でオフにします。「TwinKeys」メニューの「アップデートを確認…」でいつでも確認できます。

## メニューバー

- TwinKeys はメニューバーに鍵盤のアイコンを出します。つながっているときは塗りつぶし、つながっていないときは線だけ、つなぎ直している最中は「!」付きです。
- アイコンのメニューから、オールノートオフ、接続、キー入力、TwinKeys を開く、設定、ログイン時に起動、アップデートを確認、終了ができます。
- ウインドウを閉じても TwinKeys は動き続けます。止めるときは「TwinKeys を終了」（⌘Q）を選びます。
- 「設定」の「メニューバー」で、「ログイン時に起動」と「メニューバーだけに表示する（Dock に出さない）」を選べます（どちらも最初はオフ）。

## 音が止まらないとき

- 赤い「オールノートオフ」ボタン（⌃⌘P）を押すと、この Mac と接続先の Mac の音をすべて止めます。
- TwinKeys を終了したときと「接続解除」したときにも、両方の音を止めます。
- ノートオフが届かなかった音は、10 秒で自動的に止まります（キーを押し続けている音は止まりません）。秒数は「設定」で変えられます。0 にするとこの機能はオフになります。1〜2 秒にしても、相手の Mac から届いた音は最低 3 秒待ちます。
- 回線が切れたときは、相手から届いた音だけを止めます。メインの Mac で自分のキーから出している音は止めません。

## iPhone・iPad から Live を操作する（TwinKeys Remote）

TwinKeys Remote は、iPhone・iPad から2台の Live をまとめて操作するアプリです。シーンやクリップの再生、再生・停止、テンポ、ミキサー（音量・パン・ミュート・ソロ）、キューのキー、オールノートオフが使えます。iPhone はメインの Mac につなぎ、メインの Mac が同じ操作をバックアップの Mac にも送ります。

### 用意するもの

- TwinKeys 2.0 以降を、両方の Mac に（GO・セットの見比べ・センドは 2.1 以降）
- iOS 17 以降の iPhone・iPad（いまは TestFlight で配布中）。Apple Watch を使うときは watchOS 10 以降
- iPhone・iPad と Mac が同じネットワークにつながっていること

### Mac の準備（両方の Mac）

1. TwinKeys の「設定」を開きます。
2. 「Live との連携」で「Live に組み込む」をクリックします。Live 用の小さな部品（TwinKeysBridge）が Live のフォルダに入ります。
3. Live を再起動し、「環境設定」>「Link, Tempo & MIDI」の「コントロールサーフェス」の空いている欄で「TwinKeysBridge」を選びます。「入力」「出力」は「なし」のままで構いません。
4. TwinKeys の「設定」に「Live: 接続済み」と出れば完了です。
5. メインの Mac では、「iPhone・iPad（TwinKeys Remote）」の「TwinKeys Remote からの接続を受け付ける」をオンにします。

TwinKeys を新しくすると、Live 用の部品（TwinKeysBridge）も自動で新しくなります（2.2 以降）。「Live を再起動してください」と出たら、本番の前に Live を再起動してください。

### iPhone をつなぐ（最初に一度だけ）

1. iPhone で TwinKeys Remote を開き、Mac と同じ合言葉を入れて「保存」を押します。
2. 「ローカルネットワーク上のデバイスの検索」を求められたら「許可」を押します。
3. 「近くの TwinKeys」にメインの Mac が出たら「接続」を押します。
4. iPhone に4桁の番号が出て、Mac にも「この iPhone を許可しますか？」と番号が出ます。同じ番号のときだけ、Mac で「許可」を押します。
5. 次からは、開くだけで自動でつながります。許可を取り消すときは、Mac の「設定」>「許可した端末」で「取り消す」を押します。

### 画面

- **上の帯**：つながりの状態（メインの Mac、バックアップの遅延）、再生、停止、テンポ、位置、オールノートオフ、本番ロック。
- **セッション**：クリップのます目。押すとそのクリップを再生、空いたます目を押すとそのトラックを停止します。右端の ▶ でシーンごと再生。再生中のクリップには残り時間が出ます。
- **ミキサー**：列のどこをなぞっても音量（またはパン）が動きます。点線が 0 dB です。M はミュート、S はソロです。
- **キュー**：Mac のキューのキーと同じボタン。何をするか（Mac で書いたメモ）が大きく出ます。直前のキューと、バックアップに届いたかも確かめられます。
- **GO**：Live のシーンの並びを台本として使う画面。大きな「GO」を押すと、Live で選んでいるシーンが2台で再生され、選択が1つ下に進みます。「前へ」「次へ」は選ぶだけで鳴らしません。続けて押しても 0.5 秒以内の2回目は受け付けません。
- **ミキサーのセンド**：ミキサーの「Send A」「Send B」で、リターントラックへのセンドを動かせます（セットにリターントラックがあるとき）。
- iPhone は横向きで使うのが基本です。横向きでは画面の切り替えが右端に並びます。iPad や開いた iPhone Duo では、2列・3列に広がります。

### 2台の状態を確かめる

- Mac の画面の上の「つながり」の行に、相手の Mac（Live ✓・遅延）、つながっている iPhone の台数、Apple Watch が出ます。バックアップの Mac では「iPhone はメインの Mac に接続中」と出ます。押すと「設定」が開きます。
- iPhone の上の帯では、Mac の名前の横に Apple Watch の印が出ます（緑：つながっている、黄色：届かない）。押すと「設定」の「接続」が開きます。
- 上の帯の「バックアップ ✓ · Live ✓」は、バックアップの Mac と、その Live の両方が応答していることを表します。「Live ✗ 応答なし」のときは、バックアップの Mac で Live と TwinKeysBridge を確かめてください。
- 2台で違うセットを開いていると、黄色の帯「バックアップのセットが違います」が出ます（Mac の画面にも出ます）。押すと、違うトラック・シーンの一覧が出ます。比べるのはトラックとシーンの数と名前だけで、自動で直すことはしません。
- バックアップとの回線が切れている間に動かしたフェーダー・パン・テンポ・ミュート・ソロは、つながり直したときにバックアップへ送ります。クリップやシーンの再生は、遅れて鳴ると危ないので送りません。
- 押した操作がバックアップの Live でも動いたかを、バックアップの Mac が返事します（TwinKeys 2.2 以降）。動かなかったときは「メインでは動きましたが、バックアップの Live では動きませんでした」などと出ます。
- Live の返事が遅れたときは「Live から返事がありません」と出ます。そのあと遅れて動いたときは「Live で遅れて動きました。押し直さないでください」と出ます。
- 画面に出ていたトラック・シーンの並びと Live の今の並びが違うと（トラックを足した直後など）、押した操作は送らずに「Live のトラックやシーンが変わったので、送りませんでした」と出ます。もう一度押してください。

### 本番の誤操作を防ぐ

- **停止**と**全クリップ停止**は長押しで動きます。
- **本番ロック**（鍵のボタン）を押すと、テンポとミキサーが動かなくなります。再生・停止・クリップ・シーン・キューは使えます。解除は鍵を1秒長押しします。
- 本番ロックで止めるものは、「設定」の「本番ロックで止めるもの」で選べます（テンポ・ミキサー・クリップとシーンの再生・停止・キューのボタン）。GO・全ノートオフ・ロックの解除は止めません。ロック中は変えられません。
- 「設定」の「フェーダーの上限を 0dB にする」がオンだと、音量は 0 dB より上がりません。

### メインの Mac が止まったとき（バックアップへ切り替え）

TwinKeys 2.2 以降。バックアップの Mac でも「TwinKeys Remote からの接続を受け付ける」をオンにし、その Mac でこの iPhone を一度許可しておいてください。

- メインの Mac の応答が 3 秒ないと、iPhone に「メインの Mac が応答しません」と出ます。画面はそのまま使えます（表示は最後の状態です）。
- 「バックアップに切り替える」を押し、確認の画面で「長押しで切り替え」を 1 秒押し続けると、iPhone がバックアップの Mac につなぎ直し、その Mac がメインになります。バックアップの Mac のキーボードでもキューを出せるようになります。
- Mac だけで切り替えるときは、バックアップの Mac の画面に出る「この Mac をメインにする」を押します。この表示は、メインの Mac との回線が切れたときだけ出ます（「接続解除」を押したときや、メインの TwinKeys を終了したときは出ません）。
- 元のメインの Mac が戻ってきたら、そちらは受信だけになります（2台が同時にキーを送ることはありません）。元に戻すときは、元のメインの Mac で「この Mac をメインにする」を押すか、いまのメインの Mac で「メインに戻す」を押します（「メインに戻す」は2台がつながっているときだけ使えます）。

### Apple Watch から操作する

TwinKeys Remote 1.2 以降。Apple Watch（watchOS 10 以降）に TwinKeys が入ります。Watch は iPhone を通して動くので、iPhone の TwinKeys Remote を開いてメインの Mac につないでおいてください。本番ロックも iPhone と同じように効きます。

- **GO**：「次」に出ているシーンを2台で再生します。デジタルクラウンで前・次を選べます（選ぶだけで鳴らしません）。0.5 秒以内の2回目は受け付けません。
- **シーンを選ぶ**：シーンの一覧。タップで「次」に選びます（鳴らしません）。
- **全ノートオフ**：両方の Mac の音をすべて止めます。つながりの状態と直前のキューも出ます。
- 画面は左右にスワイプで切り替えます。

### Mac なしで試す

合言葉の画面の「サンプルで試す」で、架空のデータで画面を試せます。Mac には何も送りません。終わるときは「設定」の「サンプルを終わって Mac につなぐ」を押します。

## 卓（Yamaha）のフェーダーも切り替える（試験的）

TwinKeys 2.4 以降の試験的な機能で、初期状態はオフです。実機で確かめるまでは、本番の前にかならずリハーサルで試してください。

メインの Mac が止まったとき、もう片方の Mac が Yamaha の卓のフェーダーを動かします。止まった Mac の音が入っているチャンネルを −∞ まで下げ、同時に、止まっていない Mac のチャンネルを、止まった側が直前まで出ていた高さまで上げます。

### 動かすもの

- 動かすのはフェーダーの高さだけです。EQ・ダイナミクス・ルーティング・シーン・チャンネルの ON にはさわりません。
- 両方の Mac が卓につながり、高さを読みます。フェーダーを動かすのは、メインでない（止まっていない）側の Mac だけです。メインの Mac は、メインでいる間は読むだけです。
- 役割を切り替えたあとも同じです。今のメインが止まれば、もう片方の Mac が同じように動かします。

### 使える卓

- QL1（入力 1–32、ST IN 1–8）・QL5（入力 1–64、ST IN 1–8）
- DM3 / DM3 Standard（入力 1–16、ST IN 1）
- DM7（入力 1–120）・DM7 Compact（入力 1–72）
- DM5（入力 1–60）・DM5 Compact（入力 1–48）
- 高さの読み取り（TCP 49280 の `get` と、卓から届く `NOTIFY`）は Yamaha の説明書になく、使った人の報告（QL5・DM7・DM7 Compact）があるだけです。DM5・DM5 Compact で読めるかは、まだ確かめていません。
- 高さの書き込みは、QL は Yamaha 公式のスクリプト例（TCP 49280）、DM3・DM5・DM7 は Yamaha 公式の OSC の説明書（UDP 49900）にある方法です。
- 高さを読めないときは、行ごとに決めた高さに上げます（「決めた高さに上げる」がオンのとき。DM は公式の OSC で送ります）。QL には OSC がないため、卓に届かないあいだは動かせません。
- 卓が同時に何台までつなげるか（TwinKeys 2台と StageMix・Editor など）は、まだ確かめていません。

### 設定する（どちらか片方の Mac で）

卓の設定は両方の Mac で同じです。片方の Mac で変えると、もう片方にも自動で写ります（Mac どうしのいつもの暗号化された回線で送ります。両方の Mac に TwinKeys 2.4 以降が必要です）。確認の画面の「卓のフェーダーも切り替える」のチェックだけは、Mac ごとに覚えます。

1. 卓の「For Mixer Control」の IP アドレスを確かめ、両方の Mac を卓と同じネットワークにつなぎます。
2. 「設定」（⌘,）の「卓（Yamaha）」を開き、「試験的な機能をオンにする」にチェックを入れます。
3. 卓の機種を選び、IP アドレスを入れて「接続を確かめる」を押します。緑で「QL5 に接続済み ・ フェーダーの高さを読めています」と出れば読めています。その下に「相手の Mac（名前）も接続済み」と出れば、もう片方の Mac も卓につながっています。黄色で「高さは読めません：決めた高さに上げます」と出たときは、行ごとに決めた高さに上げます。赤は卓に届いていません。
4. 「チャンネルの割り当て」で「＋ 行を足す」を押し、1行ずつ、この Mac の音が入っているチャンネルと、相手の Mac の音が入っているチャンネルを入れます。表は役割ではなく Mac の名前で書きます（「Main Stage Mac の Ch ⇄ Backup Stage Mac の Ch」）。相手の Mac では、左右が入れ替わって見えます。番号は卓の画面と同じ（1 から）で、機種の上限を超える番号は入りません。ST IN は L と R を一緒に動かします。
5. 相手の Mac とつながる前に作った表は、つながったときに、その Mac の列になります。
6. 高さを読めているときは、行の右に、いまメインの Mac のチャンネルの高さが出ます。卓でフェーダーを動かすと、すぐに変わります。
7. 「切り替えるとき」（確認してから・自動）、「フェード時間」（すぐ・0.5 秒・1 秒・2 秒）、「メインの Ch は −∞ まで下げる」を選びます。

### 切り替える

- **確認してから**（初期値）：メインでない Mac の「この Mac をメインにする」の確認に「卓（QL5）のフェーダーも切り替える（4 行、0.5 秒）」が出ます。チェックしたまま「メインにする」を押すと、卓も切り替わります。チェックの有無は覚えていて、iPhone から切り替えたときも同じようにします。
- 卓とつながっていないとき・読んだ高さが古い（2 秒以上更新がない）ときは、確認に「卓は動かせません」と出て、Mac だけ切り替えます。
- **自動**：メインの Mac が 3 秒応答しないと、メインでない Mac が卓のフェーダーだけを一度切り替えます（Mac の役割は今までどおり、人か iPhone が切り替えます）。回線が一瞬切れただけでも動くおそれがあるので、選ぶときに確認が出ます。卓とつながっていない・高さが古いときは動かしません。
- 切り替えたあと、画面に「卓を切り替えました（0.5 秒）」と出ます。卓から読み直して、思った高さにならなかったチャンネルは黄色で出ます。
- 「卓を元に戻す」を押すと、切り替えた Mac が、自分のチャンネルを切り替える前の高さに、相手のチャンネルを元の高さに戻します。
- 画面の上の「つながり」の行に「卓 QL5 ✓」が出ます（両方の Mac で）。緑は「高さを読めています」、黄色は「決めた高さに上げます」か「つながっていません」です。

### 卓がなくても試す

- 卓の真似をする試験用のスクリプト `scripts/fake-yamaha-desk.py`（Python 3 だけで動きます）が、GitHub のソースコードにあります。何台からでもつなげます。
- ターミナルで `python3 scripts/fake-yamaha-desk.py --model ql5 --set 1=-6 --set 9=-inf` と入れて動かし、TwinKeys の卓の IP アドレスに、それを動かした Mac の IP アドレス（同じ Mac なら 127.0.0.1）を入れます。
- ターミナルで `in 1 -10` と入れると、卓でフェーダーを動かしたときと同じ知らせが、つないでいる全部の Mac に届きます。`--no-read` を付けると高さを読めない卓の真似をし、`--model dm5` などで機種を変えられます。

## QLab を2台で動かす

Figure 53 の QLab 5 を、Live と同じように2台の Mac でそろえて動かせます。方法は2つあります。

- 2台が同時に GO：MIDI ノート ○ ・ QLab モード ○
- 届いたかの確認（✓／赤）：MIDI ノート × ・ QLab モード ○（QLab の返事で確かめる）
- 2台の再生位置のずれに気づく・直す：MIDI ノート × ・ QLab モード ○
- キュー名・残り時間を iPhone と Apple Watch に出す：MIDI ノート × ・ QLab モード ○

QLab での遠隔操作（OSC・MIDI）は、ライセンスのない無料の QLab でも使えます。

### MIDI ノートで動かす（設定だけ、今すぐ）

TwinKeys はキューのキーを、両方の Mac の仮想 MIDI ポート「TwinKeys」にノートとして出しています。両方の QLab で同じノートを GO などに割り当てれば、2台とも動きます。

1. 両方の Mac で、同じワークスペースのファイル（同じキュー、同じ番号）を開きます。
2. QLab の「Workspace Settings」→「Controls」→「Workspace MIDI」を開き、MIDI 入力に「TwinKeys」を選びます（選べるかは、まだ本物の QLab で確かめていません）。
3. 「GO」の行にキューのキーのノートを割り当てます（例：Space は初期値ではノート 40（E1）。TwinKeys の「設定」→「キューのキー」で確かめられます）。「Panic」も同じように割り当てます。
4. もう片方の Mac の QLab にも、同じ割り当てをします。

できないこと：キュー名・残り時間の表示、届いたかの確認、再生位置のずれの検出。どちらかの QLab で誰かが再生位置を動かしても、TwinKeys は気づけません。

### QLab モードを使う

両方の Mac の TwinKeys が、それぞれ自分の Mac の QLab に OSC（TCP 127.0.0.1:53000）で命令します。相手の Mac の QLab に直接は送りません。メインで押したキーと iPhone の GO は、今までの暗号化された回線でバックアップの TwinKeys に届き、バックアップの TwinKeys が自分の QLab を動かします。

1. 両方の Mac で、同じワークスペースのファイルを開きます（2台はキューの「番号」で対応させます）。
2. QLab の「Workspace Settings」→「Network」→「OSC Access」で、パスコード（4桁）と権限を確かめます。TwinKeys には「view」と「control」が要ります（「edit」は要りません）。
3. 両方の Mac で TwinKeys の「設定」（⌘,）→「QLab」を開き、「TwinKeys が動かすもの」で「QLab」か「両方」を選びます。初期値は「Ableton Live」で、このときは QLab に何もしません。
4. 緑で「QLab 5.6.5 に接続済み」と出るまで待ちます。ワークスペースが2つ以上開いているときは、使うものを選びます。パスコードを入れて「保存」を押します（この Mac のキーチェーンに入り、もう片方の Mac には送りません）。
5. 「キューのキー → QLab の動き」で、キーごとに GO・次へ・前へ・Panic・Stop・番号のキューを GO・なし を選びます。初期値は Space＝GO、↓＝次へ、↑＝前へ、Esc＝Panic です。
6. もう片方の Mac も同じにします（2台で違うと、設定の「2台の QLab」に黄色で出ます）。

「QLab」だけを選ぶと、キューのキーは MIDI ノートを出しません（QLab の Workspace MIDI にも TwinKeys を割り当てていると2回動くため）。MIDI ノートも要るときは「MIDI ノートも出す（QLab だけのとき）」をオンにします。「両方」にすると、1つのキーで Live のノートと QLab の動きを両方出します。

### 2台をそろえるしくみ

- GO には「メインで待機していたキューの番号」が付きます。バックアップの再生位置が違えば、その番号のキューで GO します（「直しました」）。その番号のキューがバックアップになければ、何も鳴らしません（違うキューを鳴らすより安全なため）。
- 「バックアップの再生位置をメインに合わせる」（初期値オン）：メインで再生位置が動くたび、バックアップも同じ番号のキューに移ります。
- 「iPhone で見ていた『次』と違うときは GO しない」（初期値オン）：Mac の前で誰かが再生位置を動かした直後に iPhone の GO を押しても、思わぬキューは鳴りません。「QLab の次のキューが変わりました」と出るので、確かめてからもう一度押します。
- メインの QLab につながっていないときは、GO をバックアップにも送りません（片方だけ鳴るのを避けるため）。Panic と Stop は送ります。
- 届いたかの確認は今のキューと同じです。0.1 秒ごとに送り直し、0.3 秒たってもバックアップから返事がなければ赤で「バックアップから返事がありません」と出ます。
- 番号のないキューは、2台を対応させられません。「次へ・前へ」で動かしてください。

### iPhone と Apple Watch（QLab モード）

- 上の帯：MAIN・BACKUP・QLAB のランプ、WORKSPACE、RUNNING（動いているキューの数）、LIST、**PANIC（2台）**。PANIC は QLab の決まりで、フェード中にもう一度押すとすぐ止まります。「両方」のときは「全ノートオフ＋PANIC」です。
- GO：動いているキュー（残り時間のメーター）、次のキュー（番号・名前・種類・長さ）と「BACKUP も 13 で待機中」。▲前へ・次へ▼は2台の再生位置を動かします。STOP は長押しです。
- 一覧（LIST）：「QLab」だけのときはセッションとミキサーの代わりに出ます。タップで2台の再生位置をそこへ移します（GO はしません）。本番ロック中は 0.5 秒の長押しです。右側に、バックアップのキューの数と再生位置が同じかが出ます。
- キュー（CUE）の画面は今のままです。押すと Mac で割り当てた QLab の動きをします。
- 本番ロック中も GO・PANIC・再生位置の移動は使えます。STOP は、ロックで「停止」を止める設定のときは使えません。
- Apple Watch：左右のスワイプで GO（輪は今のキューの残り時間）・キューの一覧・PANIC（2台）。
- QLab モードには、両方の Mac と iPhone に、QLab モードの入った TwinKeys と TwinKeys Remote が要ります。古い iPhone アプリは QLab の画面を持ちません（つながりは切れません）。

### QLab がなくても試す

QLab の真似をする試験用のスクリプト `scripts/fake-qlab.py`（Python 3 だけで動きます。Figure 53 のソフトではなく、細かい点で QLab と同じではありません）が、GitHub のソースコードにあります。`python3 scripts/fake-qlab.py --port 53100` で動かし、TwinKeys を `TWINKEYS_QLAB_PORT=53100` を付けて起動すると、そのポートにつなぎます。パスコードは 1234（全部の権限）か 5678（見るだけ）です。ターミナルで `go`、`next`、`move 15`（Mac の前で操作したように）、`drop`、`mute` と入れられます。

## 困ったとき

**「ローカルネットワーク: 未許可」と出る**
- ほかの Mac から TwinKeys が見えない状態です。「システム設定」>「プライバシーとセキュリティ」>「ローカルネットワーク」で TwinKeys をオンにして、TwinKeys を開き直してください。

**相手の Mac が見つからない**
- 2台が同じネットワークにつながっているか確認します。
- 「システム設定」>「プライバシーとセキュリティ」>「ローカルネットワーク」で TwinKeys がオンか確認します。
- VPN をオフにします。VPN によっては、相手の Mac あての通信まで VPN に流してしまいます。Wi-Fi の「IPアドレスのトラッキングを制限」もオフにしてみてください。
- ファイアウォールがオンのときは、「システム設定」>「ネットワーク」>「ファイアウォール」>「オプション」で、TwinKeys が外部からの接続を受け付ける設定になっているか、「外部からの接続をすべてブロック」がオフになっているかを確認します。

**ルーターを使わず、ケーブル1本で直接つなぐ**
- 2台を LAN ケーブル1本（または Thunderbolt／USB-C ケーブル）でつなぐだけで使えます。設定はいりません。しばらくすると「システム設定」>「ネットワーク」に黄色の印と「自己割り当てIP」と出ますが、この使い方では正常です。そのまま TwinKeys で相手が見つかります。

**会場やホテルの Wi-Fi で相手が見つからない**
- 公共の Wi-Fi は、つないだ機器どうしが見えないように設定されていることがよくあります。ケーブルで直接つなぐか、自分のルーターを持ち込んでください。
- 2台は同じネットワークにつながっている必要があります。片方が Wi-Fi、もう片方が別のルーターや別の VLAN だと、お互いを見つけられません。
- スマートフォンのテザリングでも使える場合がありますが、機器どうしが見えないようにしている機種もあります。本番ではケーブルかルーターをおすすめします。

**Wi-Fi とケーブルの両方がつながっている**
- TwinKeys はケーブル側を使います。本番中は Wi-Fi をオフにすると、遅れがいちばん安定します。

**キューのキーで Live が2回動く**
- 「設定」の「キューのキーを、ほかのアプリに渡さない」をオンにし、「アクセシビリティ」で TwinKeys をオンにします。
- Live の「キーマップモード」（⌘K）に同じキーが残っていないか確認します。

**キーを押しても音が出ない**
- 「入力監視」の許可があるか確認します（画面の下に表示されます）。
- 押したキーが「キューのキー」に登録されているか確認します。
- 「キーを送信」と「キー入力」がオンか確認します。
- Live の MIDI 設定で、TwinKeys の「リモート」がオンか確認します。
- パスワードの入力中は、macOS の仕組み（セキュア入力）でキーを読み取れません。画面には「キー入力: 一時停止中（パスワード入力中）」と出て、押さえていた音はそのときに止まります。

**一覧の相手の Mac に「合言葉が違います」と出る**
- 2台の合言葉が違います。片方の Mac で「接続」メニューの「合言葉を設定…」（または「設定」>「合言葉」）を開き、「合言葉を入力…」から、もう片方の合言葉を入れてください。

**メインの Live だけ音が出る、または2回動く**
- メインの Mac で、Live の「コンピューターMIDIキーボード」をオフにします。

**アップデートしたらキー入力が効かなくなった**
- 「入力監視」と「アクセシビリティ」の一覧で、TwinKeys を一度オフにしてからオンに戻します。

**一覧の相手の Mac に「TwinKeys のバージョンが違います」と出る**
- 両方の Mac に同じバージョンを入れてください。

**iPhone に Mac が出てこない**
- iPhone と Mac が同じネットワークか確認します。
- iPhone の「設定」>「プライバシーとセキュリティ」>「ローカルネットワーク」で TwinKeys Remote をオンにします。
- メインの Mac で「TwinKeys Remote からの接続を受け付ける」がオンか確認します。

**iPhone に「合言葉が Mac と違います」と出る**
- iPhone の合言葉を、Mac の「設定」>「合言葉」と同じにしてください。

**iPhone で操作しても Live が動かない**
- Mac の「設定」に「Live: 接続済み」と出ているか確認します。出ていなければ、Live の「コントロールサーフェス」で「TwinKeysBridge」が選ばれているか確認します。
- 本番ロック中は、テンポとミキサーは動きません。

## Windows 版（試験版）

> **まだ本物の Windows PC で試していない試験版です。** 本番で使う前に、必ず自分の PC と Live で試してください。動作の確認は GitHub Actions（Windows Server 2025 と Windows 11 Arm64 のビルド・テスト）だけで行っています。

Windows 11（x64 と ARM64）で動く TwinKeys です。Mac と同じ通信を使うので、**Mac メイン＋Windows バックアップ**も、**Windows メイン＋Mac バックアップ**も、Windows 2台もつながります。0.2.0 から、Live との連携（TwinKeysBridge）と iPhone リモート（TwinKeys Remote）の受け口も入りました。どちらも**本物の Windows PC・Live・iPhone ではまだ試していません**。

### 入れ方

1. GitHub のリリース（または Actions の成果物）から `TwinKeys-Windows-x64-….zip`（ARM の PC は `arm64`）をダウンロードし、好きな場所に展開します。
2. `TwinKeys.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」>「実行」を押します。
3. 「Windows ファイアウォール」の確認が出たら、**プライベート ネットワーク**で許可します（UDP 47801 番で相手からの接続を待ちます）。パブリック ネットワークでは許可しないでください。許可しなかったときは、「Windows セキュリティ」>「ファイアウォールとネットワーク保護」>「ファイアウォールによるアプリケーションの許可」で TwinKeys にチェックを入れます。

### Live に音を届ける（ループバック MIDI ポート「TwinKeys」を作る）

Windows には Mac のような「アプリが自分で MIDI 入力を作る」標準の方法がまだないため、**ループバック MIDI ポート**を自分で作ります。TwinKeys はそこへ送るだけです。

- **Windows MIDI Services がある Windows 11 の場合**：「MIDI Settings」アプリでループバック（Basic Loopback）を作り、片側の名前を「TwinKeys」にします。TwinKeys はこの「TwinKeys」に送り、Live はもう片側を入力として読みます。
- **loopMIDI を使う場合**：loopMIDI（Tobias Erichsen 作、https://www.tobias-erichsen.de/software/loopmidi.html ）を入れ、「TwinKeys」という名前のポートを作ります。TwinKeys には同梱していません。

どちらの方法が自分の PC と Live で動くかは、まだ確かめていません。

1. 初めて開いたときの「TwinKeys の準備」で「ループバック MIDI ポート「TwinKeys」」を選び、「送ってみる」を押します。ポートが見つかると「見つかりました：TwinKeys」と出ます。
2. Live の「設定」>「Link, Tempo & MIDI」で、ループバックの入力の「トラック」と「リモート」をオンにします。
3. 「送ってみる」で Live の MIDI インジケーターが光れば準備完了です。あとは Mac と同じく MIDI マップモードでキーを割り当てます（キューは ch1、C1=36 から順、ベロシティ 127。Mac と同じノートです）。

ポートはあとから作っても、TwinKeys が数秒以内に自動で見つけます。

### Mac と Windows を混ぜてつなぐ

1. 片方（Mac でも PC でも）で合言葉を作り、もう片方に同じ10文字を入れます（Windows 版は「設定」>「合言葉」）。合言葉は Windows のユーザーごとに暗号化して保存します。
2. 両方を同じネットワークにつなぎます。相手が「近くの TwinKeys」に出たら「接続」を押します。
3. 一覧に出ないときは「IP アドレスで接続…」（Ctrl+Shift+K）で相手の IP アドレスを入れます。PC の IP アドレスは「設定」>「合言葉」に出ています。
4. メインとバックアップの決め方、届いた確認、回数、オールノートオフは Mac 同士と同じです。

Windows の相手を Mac 版が見つけると、Mac の一覧にもその PC が出ます（同じ `_twinkeys._udp` を使います）。Mac と PC が互いに見つかるかは、まだ本物の機械で確かめていません。見つからないときは IP アドレスで接続してください。

QLab は Mac だけのアプリなので、Windows 版は QLab を動かしません（QLab モードは Mac 版だけ）。Mac と PC を組み合わせたときは、Mac の「設定」→「QLab」に「相手の TwinKeys が古い（または Windows の）ため、QLab はこの Mac だけ動きます」と出ます。

### Live との連携（TwinKeysBridge、Windows）

Mac 版と同じ TwinKeysBridge（Live の中で動く小さなスクリプト）を使います。キューは今までどおり MIDI で届きます。Bridge があると、次のことができます。

- バックアップの PC が、メインのコンピューター（Mac でも PC でも）が iPhone から送った Live の操作を自分の Live でも行い、「届いた」「Live で動いた」を返します（Mac のバックアップと同じ）。
- 2台の Live のセット（トラックとシーンの数と名前）を見比べ、違うとウインドウの上に出します。
- ウインドウ下の行に「Live: 接続済み／未接続」が出ます。

入れ方：

1. 「設定」>「Live」で「Live に組み込む」を押します。`ドキュメント\Ableton\User Library\Remote Scripts\TwinKeysBridge` にコピーされます。
2. Live を再起動し、「設定」>「Link, Tempo & MIDI」の「コントロールサーフェス」で「TwinKeysBridge」を選びます（入力と出力は「なし」のまま）。
3. Live のユーザーライブラリを別の場所に移しているとき（Live の「設定」>「ライブラリ」）は、「ユーザーライブラリを選ぶ…」でそのフォルダーを選んでから組み込みます。

`Remote Scripts` の場所はほかの手順書と同じ既定の場所にしていますが、Ableton の公式の説明では確かめられていません。Live が TwinKeysBridge を見つけないときは、Live の「設定」>「ライブラリ」に出ているユーザーライブラリの場所を選び直してください。

### メインのコンピューターが止まったときは（Windows）

バックアップの PC は、メインとの接続が予期せず切れると、ウインドウの上に「⚠ メインのコンピューターが止まったときは」と出します。「この PC をメインにする」を押すと、この PC のキーボードでキューを出せます。元のメインが戻ってくると、そちらは受信だけになります。戻すときは「メインに戻す」を押します（Mac と同じ）。

### iPhone リモート（TwinKeys Remote、Windows）

1. 「設定」>「iPhone リモート」で「TwinKeys Remote からの接続を受け付ける」をオンにします（初めはオフです）。合言葉が必要です。
2. Windows ファイアウォールの確認が出たら、プライベート ネットワークで許可します（TCP 47803 番。使えないときは別の番号を使います）。
3. iPhone の TwinKeys Remote でこの PC を選びます。PC のウインドウの上に「…が TwinKeys で Live を操作しようとしています（番号 1234）」と出るので、「確認する…」を押し、iPhone と同じ4桁なら「許可」を押します。勝手にウインドウを開いて Live の前に出ることはありません。60 秒たつと取り消されます。
4. 許可した端末は「設定」>「iPhone リモート」に出ます。「取り消す」でいつでも外せます。

iPhone からの操作は、この PC の Live で動かし、バックアップ（Mac でも PC でも）にも送ります。**本物の iPhone と Windows PC の組み合わせではまだ試していません。**

### Windows 版のキーとショートカット

- キューのキーは**キーの位置**で判定します（JIS 配列でも US 配列でも同じ場所なら同じキュー）。初めは ↑ ↓ ← → Space Enter Esc です。
- 「キューのキーを、ほかのアプリに渡さない（おすすめ）」に、特別な許可は要りません。ただし**管理者として動いているアプリが前面にあるときは効きません**。Live はふだんどおり起動してください。
- TwinKeys の文字入力欄やダイアログを使っている間は、キーはそちらに入ります（Mac と同じ）。
- Ctrl+K 接続／接続解除、Ctrl+Shift+K IP アドレスで接続、Ctrl+, 設定、F1 この説明。**Ctrl+Alt+K**（キー入力のオン／オフ）と **Ctrl+Alt+P**（オールノートオフ）は、どのアプリが前にあっても効きます。
- ウインドウを閉じても TwinKeys は通知領域（タスクトレイ）で動き続けます。終了は通知領域のアイコンを右クリック >「TwinKeys を終了」。

### Windows 版のファイル

- 設定 …… `%LOCALAPPDATA%\TwinKeys\settings.json`
- 合言葉 …… `%LOCALAPPDATA%\TwinKeys\pairing.dat`（このユーザーだけが読める形で暗号化）
- ログ …… `%LOCALAPPDATA%\TwinKeys\Logs\`（「設定」>「一般」から開けます）
- TwinKeysBridge …… アプリの中の `TwinKeysBridge` フォルダー（「Live に組み込む」でユーザーライブラリにコピー）
