## New
- **QLab mode**: keep QLab 5 on two Macs together, as for Live. In Settings → QLab, set "TwinKeys drives" to QLab or Both. The default stays Ableton Live, so nothing changes unless you choose it.
  - Each Mac's TwinKeys sends commands to the QLab on that same Mac (they never leave that Mac).
  - GO carries the number of the cue standing by on the main Mac. If the backup's playhead is elsewhere, it GOes that same cue; a cue the backup does not have is not played.
  - Delivery is checked (red if no reply within 0.3 s), and the backup's playhead can follow the main's.
  - Each cue key can have a QLab action (GO, Next, Previous, Panic, Stop, GO cue number).
  - Works with the free version of QLab.
- Works with TwinKeys for Windows (test version). The list shows whether the other computer is a Mac or Windows.
- The help has a new chapter, "Running QLab on two Macs".

## Notes
- QLab mode has not been tried yet with a real QLab and real Macs. Rehearse before any show.
- To use QLab mode, update both Macs to 2.4.0.
- The QLab screens on the iPhone come with the next TwinKeys Remote (1.4.0). Until then, the cue key buttons on the iPhone drive QLab.
- Updates arrive automatically from 1.0.0 on. The new version is swapped in when you quit TwinKeys.
