## New
- **Pairing code**: only Macs that share the same 10-character code can connect, and their traffic is encrypted.
- **Connect by IP address** (⇧⌘K) when the other Mac is not listed, for example on a venue network.
- While you type a password, the window shows "Key capture: Paused".

## Fixed
- Unknown devices on the same network could connect, or pretend to be the backup Mac.
- When the network path was rebuilt after a short drop, notes could stop for about 3 seconds.
- A key held for more than 10 minutes could keep sounding on the other Mac.
- After Disconnect, the same Mac could not connect again until TwinKeys was reopened.
- With both a cable and Wi-Fi connected, TwinKeys could use the less steady Wi-Fi.

## Notes
- 0.5.0 cannot connect to 0.4.x or earlier. Use the same version on both Macs.
