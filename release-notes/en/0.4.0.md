## New
- Shipped as an Apple-notarized .dmg: no "developer cannot be verified" warning on first launch.

## Fixed
- A key released while the link was down in one direction could keep sounding on the backup Mac.
- Moving to a password field while holding a key left that note sounding.
- Pressing Connect on both Macs at once could leave them briefly unconnected.
- After switching to another Mac, the previous one could reconnect by itself.
- Macs set up from a copied settings file could not see each other.
- After an octave change, releasing one of two keys playing the same note cut the note.
- After lowering velocity all the way, it could not return to 100.
