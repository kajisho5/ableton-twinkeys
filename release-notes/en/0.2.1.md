## Fixed
- Holding a key for more than 10 seconds stopped the note (for example long pad chords).
- After Disconnect on a shaky network, the other Mac could reconnect by itself.
- A hand-edited settings file that could not be read was silently reset, which could make Live forget the port settings. The old file is now kept and you are told.
- The key-capture warning could stay on screen after the problem was solved.
