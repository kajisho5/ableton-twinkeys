## New
- **The first full release.** No more pre-releases.
- **Cue keys**: fire cues with any key you like: arrows, Space, Return, Esc and more. Each key sends a fixed MIDI note (channel 2) that does not change with the octave. Add and remove keys, and give them memos ("Next scene"), in Settings > Cue Keys.
- **Keep cue keys from other apps**: stops Live on the main Mac from also reacting to the arrows or Space and moving twice. Needs the Accessibility permission.
- **Last cue and delivery check**: the key, its memo and the count since connecting are shown large on both Macs. A ✓ shows the backup received the cue; if no answer comes within about 0.3 s, "No confirmation" appears in red. While waiting, the cue is sent again every 0.1 s, and it never fires twice.
- **Automatic updates**: new versions are downloaded in the background and installed only when TwinKeys quits. Never during a show.
- **Menu bar**: a keyboard icon shows the link and has a menu with All Notes Off, Connect and more. TwinKeys keeps running when the window is closed. Open at Login and "menu bar only" are available.
- The **piano layout** (A…; for notes) is off on a new install. If you update from 0.5.0 it stays on.

## Fixed
- No bug fixes in this version.

## Notes
- The delivery check works when both Macs run 1.0.0. With 0.5.0 on the other Mac, "Delivery cannot be checked" is shown (the cue itself still arrives).
- TwinKeys 0.4.x and earlier cannot connect.
- 0.5.0 does not update itself: install 1.0.0 by hand. From 1.0.0 on, updates arrive automatically.
