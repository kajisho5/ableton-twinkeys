## 新しくなったこと
- **QLab モード**：QLab 5 を、Live と同じように2台の Mac でそろえて動かせます。「設定」→「QLab」の「TwinKeys が動かすもの」で「QLab」か「両方」を選びます。最初は今までどおり「Ableton Live」なので、選ばなければ何も変わりません。
  - 両方の Mac の TwinKeys が、それぞれ自分の Mac の QLab に命令を送ります（その Mac の中だけでやりとりします）。
  - GO には「メインで待機していたキューの番号」が付きます。バックアップの再生位置がずれていても、同じ番号のキューを GO します。バックアップにないキューは鳴らしません。
  - 届いたかを確かめます（0.3 秒で返事がなければ赤）。バックアップの再生位置はメインに合わせられます。
  - キューのキーごとに QLab の動き（GO・次へ・前へ・Panic・Stop・番号のキューを GO）を選べます。
  - QLab の無料版でも使えます。
- Windows 版の TwinKeys（試験版）とも組めます。一覧で相手が Mac か Windows かを表示します。
- 手順書に「QLab を2台で動かす」を足しました。

## 注意
- QLab モードは、本物の QLab・Mac ではまだ確かめていません。本番の前にリハーサルで必ず試してください。
- QLab モードを使うときは、2台とも 2.4.0 にしてください。
- iPhone の QLab の画面は、TwinKeys Remote の次の版（1.4.0）から使えます。それまでの iPhone アプリでは、キューのキーのボタンで QLab を動かせます。
- 1.0.0 からは自動でアップデートされます。入れ替わるのは TwinKeys を終了したときです。
