- Project: https://github.com/ideoforms/AbletonOSC (MIT License,
  Copyright (c) Daniel John Jones and contributors)
- Revision consulted: `0ca68214bd62c9b5cb641ca34006cfd70ba94430` (2025-11-19)

TwinKeys Bridge was written from scratch. AbletonOSC was read only to confirm
how a Live Remote Script is structured (`create_instance(c_instance)` in
`__init__.py`, a `ControlSurface` subclass, a non-blocking UDP socket polled
on Live's timer, `add_<prop>_listener`/`remove_<prop>_listener`) and which Live
Object Model properties it uses. No substantial part of its source is included,
so its license text is not reproduced here. If code from AbletonOSC is ever
copied into this folder, add its full MIT notice below.

Unlike AbletonOSC (which binds `0.0.0.0` by default, see
`abletonosc/osc_server.py`), TwinKeys Bridge binds and sends to `127.0.0.1` only.
